# 蛋白设计师 · Protein Designer

一个中文、单文件、零依赖的蛋白质折叠与序列设计小游戏。用 20 种氨基酸构建最多 30 个残基的序列，在 8 个关卡中探索疏水效应、电荷与二硫键。

**在线试玩：[kevinmasai.github.io/protein-designer](https://kevinmasai.github.io/protein-designer/)**

## 立即运行

下载 `index.html`，双击即可在现代浏览器中离线运行。所有 HTML、CSS、JavaScript、关卡数据与 Canvas 2D 绘图都在这个文件中。没有安装、构建、账号、API 密钥或服务器要求。

也可以在文件所在目录运行：

```bash
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`。

## 怎么玩

1. 选择底部氨基酸按钮来追加残基。点击已有节点，再选择字母，可以替换该位置；「＋」返回追加模式。
2. 也可以粘贴单字母序列，支持空白与小写规范化，非法字符和超出 30 个残基会被明确拒绝。
3. 提交 AI 预测，观看约 3 秒、50 个优化阶段的折叠过程。
4. 同一次预测的 **形状匹配度 ≥ 关卡要求** 且 **能量 ≤ 关卡要求** 即可通关并解锁下一关。
5. 每关可请求 3 次 AI 建议，每次有两条建议和明确标注的模拟置信度。可以反复预测同一序列，探索不同低能量构象。

支持鼠标、触屏和键盘。Tab 切换按钮、Enter 确认，非输入框内 Backspace / Delete 删除，Escape 取消选中或关闭对话框。「撤销」可恢复最近的序列修改。

浏览器会自动保存关卡进度、各关序列和建议次数；本地文件与线上网页各自保存。禁用本地存储时，游戏仍可运行，但关闭页面后不会保存。重置按钮有二次确认，且仅重置本游戏。

## 实现与模型约定

这是受 [AlphaFold](https://deepmind.google/science/alphafold/) 启发的独立教学游戏，**没有使用神经网络、AlphaFold 模型或外部 AI 服务**，与 Google DeepMind 无隶属关系。

- 二维整数格点，自避链，每个位置只容纳一个残基，相邻序列残基始终相距一格。
- 4 条独立链从水平直线出发，50 个降温阶段，每阶段每条链尝试 150 次移动，共 30,000 次候选移动。移动包括随机铰链的 90° / 180° / 270° 旋转，以及局部拐角翻转。
- 温度从 3.2 指数下降到 0.035。降能移动接受，升能移动按 `exp(-ΔE / T)` 的概率接受，重叠移动拒绝。
- 最终返回搜索到的最低能量构象；能量相同时选包围盒更紧凑的构象。**目标坐标不参与折叠搜索。**
- 使用 `requestAnimationFrame` 平滑显示各阶段。插值画面是视觉过渡，所有能量与匹配计算都使用真实格点构象。开启减少动态效果时关闭位置插值。
- 动画在测试环境中约 3.4 秒；设备性能或后台标签页调度可能使其更长。

### 氨基酸与能量

| 组别 | 单字母代码 | 颜色 |
| --- | --- | --- |
| 疏水 | A V I L M F W Y | 橙色 |
| 极性 | S T N Q | 蓝色 |
| 正电荷 | K R H | 红色 |
| 负电荷 | D E | 深蓝色 |
| 特殊 | G P | 灰色 |
| 半胱氨酸 | C | 黄色 |

| 接触条件 | 能量 |
| --- | --- |
| 疏水—疏水，四邻格接触 | −1 |
| 疏水—亲水，四邻格接触 | +0.5 |
| 正—负电荷，四邻格接触 | −1.5 |
| C—C，曼哈顿距离 ≤ 2 | 每条二硫键 −3 |

仅计算非链上直接相连的残基对。亲水组包括极性与带电组；G、P 的接触能为零，C 仅贡献二硫键。C 按距离从近到远确定性配对，距离相同按序列位置排序，每个 C 至多参与一条键；这是最近优先的简化配对，不保证最大匹配。H 简化为正电荷。模型能量单位 `ε` 不是物理实验单位。

### 指标

- **形状匹配度**：遍历平移、4 次旋转与镜像，取格点集合的最大交并比（IoU），不同长度也会受罚。通关按原始精度判定，界面向下保留 1 位小数，避免把未达标数值显示为达标。
- **能量**：上述规则的总和，越低代表模型中的构象越稳定。
- **疏水核心比率**：四邻格全部被占据的疏水残基数 / 疏水残基总数；没有疏水残基时为 0。这个指标用于观察，不是额外通关条件。

8 关数据在 `index.html` 的 `const LEVELS` 中，包括 `targetShape`、匹配与能量阈值、起始序列、提示和知识点。关卡依次为紧凑球形、疏水之心、极性外衣、电荷搭桥、二硫锁扣、协同折叠、折叠迷宫、设计师试炼。

「AI 建议」是本地启发式规则，不会联网，置信度是模拟展示值，不是 pLDDT，也不是经过校准的成功概率。真实蛋白质的折叠与设计是三维问题，这个简化模型不能用于真实生物实验。更多结构知识可浏览 [RCSB PDB](https://www.rcsb.org/)。

## 验证

已完成 64 次固定种子的模拟检查，以及浏览器中的完整 8 关流程、编辑、上限、错误输入、建议次数、刷新保存、失败判定、离线加载、触屏模拟、存储禁用和减少动态效果检查。详见 [TESTING.md](TESTING.md)。

实际通关结果取决于随机搜索，起始序列不保证每次成功；可以修改后再试，也可以直接重复预测。核心程序没有网络请求，仅主动点击帮助中的外部学习链接时会访问对应网站。

## GitHub Pages

仓库使用 `main` 分支根目录部署，不需要构建工具。修改 `index.html` 并提交到 `main` 后，GitHub Pages 会更新网页。仓库中唯一的应用源码就是 `index.html`；README 和验证记录是辅助文档。
